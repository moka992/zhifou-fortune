# v1.1.0

## 中文

本版集中完善占卜、小工具、跨屏布局和交互反馈。版本号 `1.1.0`，Android 版本代码 `17`。

### 主要变化

- 四牌塔罗提供手动选牌、可选问题和逆位、离线牌义、慢速翻牌与独立的按需 AI 解读；明确区分现代四牌布局与韦特原著。
- 原创 3D 硬币使用实际双面模型和明亮金属光照；铜钱卦采用更清晰的阴阳纹饰、投掷与阴影。
- 多面骰子采用刚体运动，支持分档摇晃力度与碰撞反馈，保留既有几何、点数、相机与结算规则。
- 按动作区分触觉：抽牌、翻牌、落牌、旋转、碰撞、刻度、确认、取消与开关不再统一套用一种短震。拖动根据位移、速度和可取消阈值产生反馈。
- 检查独立马达能力；支持时使用有限包络或组合波形，不支持时使用系统调校的语义反馈。低优先级反馈不会打断落点、确认等关键反馈。
- AI 与语音配置增加平台、模型预设和自定义入口；保留手动测试及原有验证缓存。解读措辞更自然，普通问题减少重复提示，安全边界与来源说明保留。
- 改进“我的”导航、长文本输入、语音忙碌提示、分页、图标端点、返回位置记忆与横屏、小屏和大字体布局。

### 分发与隐私

- Android 8.0 / API 26 及以上，仅 `arm64-v8a`。
- 下载附件仍为**调试签名、可调试体验包**，不是应用商店生产包。沿用原签名，覆盖安装保留本地数据；不要为升级先卸载。
- APK 包含离线语音资源；语音模型二进制不提交到 Git。密钥、签名私钥、个人配置、测试截图和设备信息不上传。
- Blender 工程可能保存本机路径，因此不随源码发布。原创 GLB、渲染图片、建模脚本及所需字体许可随项目提供，工程可在本地重建。
- SHA-256 见 Release 附件 `SHA256SUMS.txt`。

### 验证与限制

- 离线构建、237 项 JVM 测试和 Android Lint 通过；无测试失败、错误或跳过。Lint 尚有 75 项警告、26 项提示，不宣称零告警。
- APK 的版本代码、最低/目标系统和签名已核验。
- 触觉隔离实机测试完成 20 类事件与渐进拖动；关闭触觉时不提交反馈。受测设备走 12 种系统语义路径，避免原先单一短震退化。
- 四牌抽取在实机完成，四张牌无重复，结果页正常，测试进程未发现崩溃。所有测试均未调用付费 AI 接口。
- 公共接口返回成功只能证明请求被接受，不能代替马达加速度测量或主观触感验收。受测设备未公开精细包络、振幅或 primitive 支持；其他马达、低端设备、无障碍与生产签名性能仍需更多验证。
- 不宣称复制 Threads 的专有波形，也不宣称各设备触感一致。详见 [触觉设计](../haptic-design.md)。

## English

Version `1.1.0`, Android version code `17`, refines readings, utilities, adaptive layouts, and interaction feedback.

### Highlights

- Four-card tarot with manual picks, optional questions/reversals, offline references, a slower reveal, and explicitly requested AI interpretation. Modern spread conventions remain distinct from Waite's original text.
- Original double-sided 3D coins with bright metallic lighting; clearer casting-coin faces, motion and shadows; rigid-body polyhedral dice with strength-sensitive shake input.
- Contextual haptics for extraction, turning, landing, rotation, collisions, detents, toggles, confirmations and cancellation. Spatial/velocity-sensitive gestures include reversible thresholds rather than a timer-driven buzz.
- Capability-aware finite envelopes, supported-only primitive scores, OEM semantic fallbacks, and priority arbitration to prevent tiny ticks interrupting important feedback.
- Provider/model presets for AI and transcription, custom configuration, existing connection-validation caching, more natural interpretation wording, and improved composer/navigation/adaptive-layout behavior.

### Distribution

Android 8.0+ / API 26+, `arm64-v8a`. The download remains a **debug-signed, debuggable evaluation APK**, not a production store build. Matching-signature installations can update in place without clearing local data.

The APK includes offline speech resources; speech-model binaries are excluded from Git. Credentials, signing keys, private preferences, device identifiers and test screenshots are not published. Blender authoring files remain local because they may retain workstation paths; runtime assets and reproducible generators are included. Release attachments provide SHA-256 checksums.

### Verification and Limits

Offline build, all 237 JVM tests, Android Lint and APK signature verification passed. Lint retains 75 warnings and 26 informational findings. A physical-device fixture exercised 20 tactile events, progressive dragging and disabled-feedback silence, using 12 system semantic routes. Four-card selection completed with four distinct cards and no crash in the test process. No paid AI request was made.

API acceptance is not a measurement of motor output or subjective quality. The tested device exposes no advanced envelopes, amplitude control or primitives. Additional actuator families, low-end performance, accessibility and production-signed profiling remain to be validated. The application does not claim to reproduce proprietary Threads waveforms or identical sensations across devices.
