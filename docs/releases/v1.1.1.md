# v1.1.1

## 中文

版本号 `1.1.1`，Android 版本代码 `18`。本版集中修正四牌塔罗的选牌触觉与翻牌文字层级，并更新项目展示。

### 更新

- **逐牌棘轮触觉**：每张牌的中心经过牌列中线时触发一次短促轻触，而不是按累计距离重复震动。慢滑、快滑、反向与惯性减速保持相同的卡牌格点；抑制边界微抖，停止后不补震。
- **避免漏格与叠震**：牌列使用短 Tick，不再被原先的 60 ms 间隔隔掉相邻牌。抽出、翻面和确认反馈仍有更高优先级，关闭触觉和系统偏好照常生效。
- **翻牌文字层级**：“1 · 现状”“2 · 阻碍”等位置说明移到独立的下层，翻牌时淡出、落定后恢复，不再浮在放大的牌面上方。
- **项目头图**：README 增加与独立 Skill 同一视觉家族的原创头图；实际界面截图与演示保留，宣传图片不冒充界面。

抽牌结果、牌义、牌阵、AI 提示词、服务配置和历史保存规则不变。现有本地资料无需迁移。

### 安装与隐私

Android 8.0 / API 26 及以上，`arm64-v8a`。附件仍为**调试签名、可调试体验包**，不是应用商店生产包；与旧版签名一致时可直接覆盖安装，不要先卸载。

APK 包含离线语音资源，模型二进制不进入 Git。密钥、个人资料、设备标识、签名私钥和私人截图不随源码或发布附件上传。下载文件的 SHA-256 见同一 Release 的 `SHA256SUMS.txt`。

### 验证与限制

- 全部 251 项 JVM 测试、离线构建和 Android Lint 已通过；Lint 无错误，仍有 77 项警告、26 项提示。
- 专项测试覆盖卡牌中心对位、手指起点无关性、正反向、常见刷新率、连续牌格、防抖、停止静默和关键动作优先级。
- 实机隔离页逐项记录牌序号、过线位置及触觉请求，用户已确认当前震动效果。接口接受请求不等于跨设备触感一致；本机测试不使用真实账户资料，也不调用付费 AI。
- 显示帧采样与马达延迟存在物理上限；极快滑动若一帧跨过数张牌，不会在事后排队补震。不同马达的强度与细腻度仍受硬件和系统设置影响。

## English

Version `1.1.1`, Android version code `18`, focuses on four-card tarot browsing and reveal polish.

### Changes

- Card-center ratchet haptics replace sub-card travel pulses. Each card crossing the rail center generates a short tick in either direction, including a user-initiated fling. Boundary jitter is suppressed; stopped cards never cause queued feedback.
- Short detent effects and revised arbitration avoid the previous 60 ms gap swallowing adjacent cards. Draw, turn and confirmation cues still take priority. Application and system haptic preferences remain authoritative.
- Position captions sit in a separate layer beneath flying cards, fade out during a reveal, and return after settling.
- A new original README cover matches the independent skill's visual family. Presentation artwork remains explicitly separate from real-device captures.

Draws, references, spread rules, AI prompts, provider settings and history behavior are unchanged. No data migration is required.

### Distribution and Verification

Android 8.0+ / API 26+, `arm64-v8a`. This remains a **debug-signed, debuggable evaluation APK**, not a production store build. Update matching-signature installations in place to retain local data. Offline speech resources remain bundled; model binaries are excluded from Git. Credentials, personal data, device identifiers and signing secrets are not published. See the attached `SHA256SUMS.txt` for the APK checksum.

All 251 JVM tests, the offline build and Android Lint passed. Lint reports no errors, 77 warnings and 26 informational findings. Focused checks cover geometric card alignment, start-position independence, direction changes, common refresh rates, adjacent detents, jitter suppression, stopped-state silence and priority arbitration. An isolated physical-device fixture recorded card slots, crossing positions and accepted haptic requests; the user confirmed the current feel. No private account or paid AI call was used.

Per-frame sampling and actuator latency limit extremely fast gestures. Multiple crossings within one frame do not produce a delayed queue after the cards stop. API acceptance is not a guarantee of identical motor output across devices. See [haptic notes](../haptic-design.md) and [cover provenance](../media/README.md).
