## 一、现状盘点（逐字，便于对照）

### 1.1 今日运势 / 今日能量（本地生成，无 LLM）
`FortuneOracle.today()`（`MainActivity.kt:3305`）按 `日期|昵称|生日关键词` 哈希取种子，从两份各 6 条的小库里各取一条，拼成 `body + advice`，分数为 `58..96`。

- `dailyBodies`（6 条）：
  > 今天适合把混乱的事情重新排队。先处理最能改变局面的那一步，其余事项保持观察。
  > 外部变化会比较多，但真正重要的是你的节奏。不要被临时消息牵着走。
  > 今天的机会来自一个不起眼的细节。多检查一次记录、数据或对话，会减少后续阻力。
  > 适合修复关系和补齐承诺。表达要短，行动要实，效果会比解释更好。
  > 能量偏向收拢。减少新承诺，整理已有资源，会比强行扩张更有价值。
  > 今天宜主动，但不宜冒进。先发出明确试探，再根据反馈调整。

- `dailyAdvice`（6 条）：
  > 把今天的目标压缩成一件可以完成的事。 / 重要回复延迟十分钟再发。 / 先确认事实，再判断态度。 / 保留一个退出选项。 / 把模糊担心写成三个具体问题。 / 不要让焦虑替你安排优先级。

- 实际组合上限：6×6=36 种（且 advice 选择耦合于 body+score）。
- "今日能量"只是 UI 上对 `score` 数字的标签（`FortuneDial`，`MainActivity.kt:2648`），副标题"结合日期与个人关键词生成"属实。

## 二、设计目标与原则

1. **认识论分层**：把"预测"重新定位为"结构化反思/情境推演工具"。占卜的价值不在断言未来，而在强迫决策者把隐含假设显性化、补全盲点。文档与提示词都贯彻这一点。
2. **四层文本结构**（经—传—注—析）：
   - 经：卦辞/爻辞原文（考据确证的通行本）。
   - 传：《彖》《象》《文言》《系辞》等对卦的释义。
   - 注：历代代表性注疏（王弼《周易注》、程颐《伊川易传》、来知德《周易集注》等）。
   - 析：结合现代决策科学的推演（风险、可逆性、认知偏误等）。
   每层显式标注，避免把"古文意译"误当"经文原文"。
3. **变爻优先**：占断严格依动爻数量决定"取用何经何传"（见 §3.2），让动爻真正影响结论，而非仅作描述。
4. **多维与多元**：每次结论按"问题相关维度"取舍展开（决策/事业/关系/财运/健康/人际），且至少给出**两条不同路径或两种立场**，避免单一断语。
5. **严谨边界**：引文注篇章；不确定明示；区分概率性建议与确定性建议；不替代医疗/法律/金融/心理专业判断；不制造恐惧与迷信消费。
6. **本地可降级**：所有 AI 能力都要有"无 Key/无网"时的本地回退，且回退质量也要比现状更好（靠扩充的本地数据表）。

## 三、理论基础（建议调用的成熟参考）

### 3.1 《周易》经传体系
- **经**：六十四卦卦辞、三百八十四爻爻辞（通行本《周易》古经）。
- **传**（《易传》十翼）：彖传（断一卦之体）、象传（大象言卦象君子取法、小象言爻象）、文言（乾坤特有）、系辞（总论）、说卦（八卦取象）、序卦（卦序理路）、杂卦（卦义对比）。
- 价值：使解读有"原典锚点"，而非泛泛抒情。

### 3.2 变爻占断规则（朱熹《易学启蒙》/《周易本义·筮仪》）
按动爻数决定取用（这是铜钱卦的核心占断逻辑，当前完全未用）：
- **0 动爻（六爻皆静）**：以本卦卦辞断之。
- **1 动爻**：以本卦动爻之爻辞断之。
- **2 动爻**：以本卦两动爻爻辞断之，以上爻为主。
- **3 动爻**：以本卦卦辞与变卦卦辞合断，以本卦为主。
- **4 动爻**：以变卦两不动爻爻辞断之，以下爻为主。
- **5 动爻**：以变卦不动爻爻辞断之。
- **6 动爻**：以变卦卦辞断之（乾坤则用"用九/用六"）。
- 价值：让"动爻"从描述文字变成决定取材的变量，结论随卦象真正分化。

### 3.3 纳甲六爻筮法（京房一系，铜钱卦的传统解读框架）
铜钱卦（金钱卦/文王卦）在历史上即以六爻筮法解读，可作为"深度解读"的可选层：
- 装卦：安世应、纳甲（干支配六爻）、起六亲（父母/兄弟/子孙/妻财/官鬼）、按日干起六神（青龙/朱雀/勾陈/螣蛇/白虎/玄武）。
- 用神：按所问事类取用神（如问功名看官鬼、问财看妻财、问病看官鬼与子孙、问出行看子孙等）。
- 断卦：看用神旺衰、生克、冲合、空破、动变。
- 价值：提供一套**与问题类型挂钩**的取象体系，使"事业/财运/关系"等维度有传统依据而非拍脑袋。
- 取舍：体系较重，建议作为"进阶解读"开关，默认走 §3.1+§3.2 的经传路线，用户可显式开启六爻深度解读。

### 3.4 其他传统资源（扩充答案与多元解读时调用）
- 焦延寿《易林》：4096 变（每卦六爻皆变对应一首辞），历史最详尽，可作为"变卦诗意解读"的素材库。
- 王弼《周易注》、程颐《伊川易传》、来知德《周易集注》、高亨《周易古经今注》《周易大传今注》、李镜池《周易探源》：历代与现当代代表性注疏，用于"注"层。
- Richard Wilhelm / Cary F. Baynes 英译本及注：跨文化对照，便于双语回答与学术严谨。

### 3.5 现代决策/认知科学框架（"析"层与对话方法论）
- **可逆/不可逆决策**（Bezos"双向门/单向门"）：判断决策可逆性，决定投入多少审慎。
- **事前验尸（pre-mortem）**：假想已失败，反推最可能原因。
- **基础率（base rate）与外部视角（outside view）**：避免仅凭个案内部视角。
- **认知偏误清单**（Kahneman）：锚定、可得性、确认偏误、损失厌恶、过度自信、沉没成本等——用于"关键提醒"维度。
- **时间窗与不对称收益**：评估"等待成本"与"机会衰减"，避免在不可逆窗口上拖延。
- **情境框架**：OODA、CYNEFIN（区分简单/繁杂/复杂/混沌/混乱情境，给不同应对策略）、艾森豪威尔矩阵。
- 价值：让"建议"从口号（"先做低风险验证"）升级为有依据的决策方法，且可针对情境分支。

## 四、分模块优化方案

### 4.1 今日运势 / 今日能量（本地增强 + 可选 AI）
**结构升级**（本地仍可离线生成）：
```
[今日基调]   一句定性 + 节气/建除参考（见 §5.1）
[宜]          2-3 条（动词开头、可执行）
[忌]          2-3 条
[维度简评]    事业 / 关系 / 财运 各一句（替换静态 InsightStrip）
[一句箴言]    取自经典，注篇章
```
- 扩充 `dailyBodies`/`dailyAdvice` 为**带分类标签的结构化题库**（基调/宜/忌/维度/箴言各成库，按种子组合），组合空间从 36 提升到数万级。
- 维度简评库按"当日基调 × 维度"取，使事业/关系/财运**真正逐日变化**。
- 可选 AI 模式：若配置了 Key，用更丰富的提示词（见 §4.5 的"每日"变体）生成个性化当日解读；否则走本地结构化库。
- 示例（mock，升级后质量示意）：
  > **今日基调**｜收拢而非扩张，先盘点再行动。（建除：平日宜整理）
  > **宜**｜核对一处易出错的数据；给一个被搁置的关系发短消息；保留一个退出选项。
  > **忌**｜一次性承诺全部资源；凭一时气氛答复重要事项。
  > **维度**｜事业-稳中推进，重在复核而非加码；关系-短而实的表达胜过解释；财运-控制变量，避免追加投入。
  > **箴言**｜"君子以俭德辟难，不可荣以禄。"——《否·大象》

### 4.2 事业·关系·财运维度概述（从静态升级为生成）
- 改造 `InsightStrip`：不再写死，读取当日/当次生成的维度简评。
- 维度可按问题类型动态选取（如问事业则事业在前、并自动展开；其余折叠）。
- 每个维度建议三档文案：**定性（一两字基调）+ 一句依据 + 一句行动**，避免空泛。

### 4.3 铜钱卦本地 `body`/`advice`（卦象数据表 + 变爻占断）
**新增本地数据资产**（见 §5.2）：为 64 卦建立
```
卦名 / 符号 / 卦辞（通行本，校勘定本）/ 大象传要点 / 一句话卦象释义 / 关键词（如 乾-刚健自强、坤-厚德载物、屯-初创艰难、蒙-启蒙蓄德、讼-慎争避讼、师-节制师出、比-亲附择善…）/ 本卦-变卦关系提示
```
**body 重构**：依 §3.2 变爻规则取用相应经传，输出包含"本卦→变卦、动爻、取用经传、卦象释义"的还原式描述，而非通用模板。
**advice 重构**：按"卦象关键词 + 动爻取用文 + 现代决策框架"生成 2-3 条针对性建议，而非常量。
- 示例（mock，1 动爻情形）：
  > **本卦**｜水雷屯 ☵☳（初九动）→**变卦**｜风地观 ☴☷
  > **取用**｜一爻动，以本卦初九爻辞断之："磐桓，利居贞，利建侯。"
  > **象解**｜屯者物之初生，磐桓谓难行而徘徊；利居贞，宜守正不宜妄动；利建侯，宜借辅佐以立根基。
  > **建议**｜①此为初创期，宜定位而非扩张；②动在初爻，根基未稳，先建一可依赖的支点（人/资源/流程）；③变至观卦，旁观一阵再下结论，避免在信息不全时定调。

### 4.4 答案之书（问题语义化匹配 + 扩充题库）
- 扩充题库并加**分类标签**（行动/等待/确认/边界/资源/信息/关系/勇气/节奏…），每条仍为 `answer + advice`，并加 `tags`。
- 选择策略：本地用**关键词命中 tags**（问题含"等/迟/快"→节奏类，含"钱/投入"→资源类…）；配置 Key 时用 LLM 做语义匹配并生成一句针对问题的引导。
- 仍保留"随机性"以维持趣味，但在 tag 命中集合内随机，命中空则全库随机。
- 这把"答案与问题无关"的割裂感消除，同时不破坏抽签体验。

### 4.5 AI 解读提示词（系统 + 用户模板升级）
**系统提示词（建议）**：
```
你是"知否运势"的占卜解读顾问，贯通《周易》经传体系、传统筮法（含变爻占断与纳甲六爻）与现代决策/认知科学。
认识论立场：占卜是"结构化反思工具"，用以显性化隐含假设、补全盲点，而非预测确定未来。
解读方法：
1. 还原卦象：本卦/变卦、动爻数与位、互卦/错综（必要时）、取用何经何传（依变爻占断规则）。
2. 分四层呈现：经（卦辞/爻辞原文，注篇章）、传（《彖》《象》等释义）、注（历代注疏，注明出处）、析（结合现代决策框架的推演）。
3. 多维研判：按问题相关度在 决策/事业/关系/财运/健康/人际 中取舍，每维给"定性+依据+行动"。
4. 多元结论：至少给出两条不同路径或两种立场，标明各自前提与代价。
5. 宜忌：宜/忌各 2-3 条，动词开头、可执行；宜忌须与卦象/动爻有逻辑关联。
6. 置信度与边界：标注不确定处；区分概率性建议与确定性建议；不替代医疗/法律/金融/心理专业判断；不制造恐惧或诱导消费。
语言：简体中文，专业、克制、清楚，不堆砌玄虚术语；引用经典注明篇章，意译须明示。
```
**用户提示模板（建议，结构化注入 + 动爻信息 + 输出契约）**：
```
请解读以下占卜结果。
【占类】${kind}  【时间】${timeLabel}  【能量分】${score}
【问题】${question 或 "未填写具体问题，请按一般情境解读"}
【卦象】本卦 ${mainHex.name}${mainHex.symbol} / 变卦 ${changedHex.name}${changedHex.symbol}
【动爻】${movingText（如 "第2、5爻动" 或 "六爻皆静"）}
【本地释义】${body}  【本地建议】${advice}

输出（严格按此 JSON 结构返回，便于前端解析；若不支持 JSON 则按下列小标题输出）：
```

## 六、工程考量（落地时注意，本稿不实现）

1. **Token/延迟/成本**：结构化四层 + 多维会使单次输出变长；建议本地先尽量承载（数据表），AI 只补"析"层与个性化，控制 `max_tokens` 与调用频次；今日运势可缓存（同日不重复请求）。
2. **结构化输出**：建议 AI 解读返回 JSON（§4.5），前端按字段渲染，与后续 Markdown 渲染需求解耦；本地回退用结构化库直接渲染。
3. **离线回退**：每个 AI 能力都要有"无 Key/无网"路径，且回退质量 = 扩充后的本地数据表（§5），保证未配 Key 用户体验也明显优于现状。
4. **历史压缩**：对话超 20 条改为"摘要 + 近 N 条原文"，避免重要上文被截断丢失。
5. **引文校勘**：卦辞/爻辞须用定本，建立校对流程，避免 LLM 误造经文（系统提示已要求明示意译/存疑，但本地表仍是可信锚点）。
6. **版本与可灰度**：提示词与数据表建议版本化，便于 A/B 与回滚；新提示词可先灰度给开了 Key 的用户。
7. **既有约束不变**：保留"占卜保留 3 天内前 5 条、聊天保留近 30 条"等已有上限，不因提示词变更而动数据层。
